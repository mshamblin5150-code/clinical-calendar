# Research the Graphite Semantic Palette

Type: research
Status: resolved
Blocked by:

## Question

Which high-trust primary sources and existing launcher-brand evidence should define Graphite as the neutral default, the signed-out in-app verification identity, and a complete dark Clinical Calendar semantic palette with restrained cobalt or teal accents?

## Answer

Use the existing launcher master's near-black graphite, layered charcoal,
silver, and tiny green-teal signal as Graphite's brand anchor. The proposed
semantic system keeps teal (`#37D6B4`) for primary action/sync, cobalt for
Clinical Session and Scheduled Hours, violet only for Work Shift and
Over-Target Hours, and provides complete surface, text, control, calendar,
progress, feedback, synchronization, Enhanced accessibility, contrast, and
prohibited-pairing contracts. Graphite is the new-Student default and always
styles the signed-out in-app email/code verification card; it does not style
the email HTML or override a signed-in Student's saved theme.
