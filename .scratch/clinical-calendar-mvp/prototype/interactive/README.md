# Clinical Calendar interactive prototype

This is a disposable, in-memory prototype of the accepted Variant F interface. It does not save or sync real clinical data.

The functional review surface now includes Work Shift and Clinical Session entry, 12-hour military-time templates, all-or-nothing conflict removal, movable Protected Days, placement and Preceptor progress, past-session confirmation, Evaluation Plan documentation, Month/Week/Agenda views, attention workflows, and responsive phone navigation. Reloading deliberately restores the fictional starting state.

## Run locally

```powershell
npm install
npm run dev
```

Then open `http://127.0.0.1:5173/`.
