# Clinical Calendar UI Concepts

Three structurally different concepts for the core calendar and progress experience, generated with the built-in image-generation tool on 2026-08-02.

- [Variant A — Calendar Command Center](Variant%20A%20-%20Calendar%20Command%20Center.png): week calendar dominates, with placement progress and attention in a contextual rail.
- [Variant B — Progress Navigator](Variant%20B%20-%20Progress%20Navigator.png): placement progress and evaluation thresholds dominate, with an upcoming-session timeline.
- [Variant C — Monthly Planning Board](Variant%20C%20-%20Monthly%20Planning%20Board.png): month-scale, multi-date schedule planning dominates, with templates and all-or-nothing conflict review.
- [Variant D — Dark Composite](Variant%20D%20-%20Dark%20Composite.png): combines Variant B's shell, Variant C's calendar, and Variant A's circular progress, review warning, and phone navigation in the Student's preferred dark theme.
- [Variant E — Borg Systems Grid](Variant%20E%20-%20Borg%20Systems%20Grid.png): restrained green biomechanical system with a focused planning flow rather than the original four-column bottom panel.
- [Variant F — Borg Tactical Console](Variant%20F%20-%20Borg%20Tactical%20Console.png): heavier tactical-console system with a compact staged bottom tray.
- [Variant G — Picard LCARS Heritage](Variant%20G%20-%20Picard%20LCARS%20Heritage.png): evolved amber/plum LCARS direction with a right-side staged planning inspector.
- [Variant H — Picard Command Glass](Variant%20H%20-%20Picard%20Command%20Glass.png): quieter brass/navy Picard-era command surface with a minimal collapsible command ribbon.

Each concept includes a desktop surface and a related phone adaptation. These are design references for a throwaway interactive prototype, not production UI assets.
