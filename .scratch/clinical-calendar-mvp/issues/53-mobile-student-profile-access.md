# Add Student Profile Access to Mobile Header

Type: task
Status: resolved
Blocked by: none

## What's wrong

The desktop header exposes the Student Profile avatar, but the mobile header hides the entire desktop action group and therefore hides profile access.

## What I expected

The mobile header shows the same photo-or-initials avatar and opens Student Profile directly without requiring navigation through another menu. The bottom Settings tab opens the same complete application menu as the three-line button.

## Answer

The mobile header now displays the same photo-or-initials avatar as desktop and opens Student Profile directly. The mobile Settings tab now opens the complete application menu, matching the three-line button and exposing Clinical Placements, Student Profile, Settings, Notifications, and Help. Help documents both entry points. The production build passes and the interactions were verified at 390 × 844.
