# Apply a Cross-Era Borg Semantic Palette

Type: task
Status: resolved
Blocked by: none

## What's wrong

Work Shifts and Clinical Sessions use nearly identical green treatments, while Protected Days use an unrelated purple treatment. The progress wheel uses generic traffic-light colors rather than a coherent cross-era Borg visual hierarchy.

## What I expected

Use recurring Borg visual language across *The Next Generation*, *First Contact*, *Voyager*, and *Picard* to make Work Shifts, Protected Days, and placement progress immediately distinct while remaining readable. Treat exact hex values as accessibility-calibrated visual inferences because no official canonical Borg palette exists.

## Answer

Cross-era official-source research established a shared hierarchy of charcoal/gunmetal structure, dominant green illumination, metallic gray, and sparse red signals rather than a single canonical palette. The prototype now renders Work Shifts in cool gunmetal with a muted green-steel rail, Protected Days in striped dormant graphite with regeneration-silver labeling, and the placement wheel in Collective green, industrial ochre, and restrained optic red. Desktop and 390 px phone QA confirmed distinct computed colors, zero horizontal overflow, and no browser console warnings or errors; the production build passes.
