# Resolve Evaluation Reminders When Requirements Are Documented

Type: task
Status: resolved
Blocked by: none

## Parent issue

Reported during QA of ticket 07.

## What's wrong

Documenting an Interim Review does not update or clear the corresponding warning.

## What I expected

The warning derives from the Evaluation Plan. Each Interim Review part is tracked separately, and the warning changes or clears when all currently due parts are documented.

## Steps to reproduce

1. Open the Evaluation Plan from the Interim Review warning.
2. Mark the relevant Interim Review requirements documented.
3. Return to the calendar.
4. Observe that the warning remains unchanged.

## Blocked by

None - can start immediately.

## Answer

Each Interim Review part is documented separately. Once both current parts are Documented, the warning changes to Evaluations up to date and the notification count falls.
