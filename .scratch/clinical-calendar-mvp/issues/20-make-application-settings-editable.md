# Make Application Settings Editable

Type: task
Status: resolved
Blocked by: none

## Parent issue

Reported during QA of ticket 07.

## What's wrong

Settings display values but provide no controls to change them.

## What I expected

The Student can change supported preferences and save them, with the current values visible when Settings is reopened.

## Steps to reproduce

1. Open Settings.
2. Select any displayed preference.
3. Observe that it cannot be changed.

## Blocked by

None - can start immediately.

## Answer

Week start, time display, theme, and sync-mode preferences are now editable and saved in prototype state.
