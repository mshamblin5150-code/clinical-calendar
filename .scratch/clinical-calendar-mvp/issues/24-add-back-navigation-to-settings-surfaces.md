# Add Back Navigation to Settings Surfaces

Type: task
Status: resolved
Blocked by: none

## What's wrong

Management and Settings surfaces only expose a close icon and do not provide an obvious Back action.

## What I expected

Each modal provides a labeled Back action that returns to the application menu without losing prototype state.

## Answer

Settings and Clinical Placement management now provide a labeled Back button that returns to the Clinical Calendar menu. Rendered QA verified Settings -> Back restores the menu without reloading the prototype.
