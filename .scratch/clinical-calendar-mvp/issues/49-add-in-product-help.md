# Add In-Product Help

Type: task
Status: resolved
Blocked by: none

## What's wrong

The prototype has no Help entry explaining its calendar states, scheduling workflow, progress calculations, evaluations, notifications, or current storage limitations.

## What I expected

Desktop and mobile expose a clearly labeled Help button. Help opens a readable, scrollable guide covering every primary workflow and the meaning of the Borg-themed status treatments. Help is also available from the application menu.

## Answer

Help is now directly available from desktop and mobile headers and from the application menu. Its nine shared workflow sections cover calendar states, batch scheduling, date-driven completion, Protected Days, placement and total progress, Preceptors, Evaluation Plans, attention/notifications, and settings/profile/storage limitations. Phone, phone-landscape, and tablet QA found no clipped content or horizontal overflow.
